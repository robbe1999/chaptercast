# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting: **Security tab, "Report a vulnerability"**. Include steps to reproduce and the impact you see. You will get an acknowledgement within a few days.

## Leaked credentials

If you find an API key or token in this repository or its history, report it privately as above. Do not use it.

## Scope

The design and threat model are documented in [docs/SECURITY.md](docs/SECURITY.md), including known limitations.
